# 操作介面安全示範

這裡包含 10 張從既有 Cable1/A 結果複製的相機原圖，只用來測試「補訓資料中心」介面。正式 demo 圖皆為 3072×2048，未使用 640×640 預處理圖或已畫框圖。

## 開啟方式

雙擊 `open_demo.bat`。

## 可測試功能

- 依「直接訓練／需要補標／顏色校正」篩選。
- 單張勾選與取消勾選。
- 使用 Ctrl 或 Shift 多選縮圖。
- 從待送清單移除並返回。
- 測試三張處理路徑卡與數量更新。
- 雙擊縮圖放大。

## 安全範圍

- 不會啟動補訓。
- 不會修改正式 `Result`、正式 review manifest 或訓練資料。
- 按下任何送出按鈕只會顯示示範結果，再重新開啟剩餘清單。
- 關閉程式後狀態不保存；下次開啟會重新載入 10 張。

圖片來源仍保留在正式 `Result/20260714/Cable1/A`，此處只有副本。

先前誤用的 640×640 圖已移至 `archive/preprocessed_640`，不會被 demo 載入。
